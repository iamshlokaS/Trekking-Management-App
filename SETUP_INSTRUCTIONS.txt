OPTION 1: WINDOWS (Easiest!)
─────────────────────────────
1. Extract the ZIP file
2. Double-click: run.bat
3. Wait for Flask server to start
4. Open browser: http://localhost:5000
5. Login with: admin / admin123

OPTION 2: MAC / LINUX
──────────────────────
1. Extract the ZIP file
2. Open Terminal in this folder
3. Run: chmod +x run.sh && ./run.sh
4. Wait for Flask server to start
5. Open browser: http://localhost:5000
6. Login with: admin / admin123

OPTION 3: MANUAL SETUP
───────────────────────
1. Extract the ZIP file
2. Open Terminal/Command Prompt in this folder
3. Create virtual environment:
   - Windows: python -m venv venv && venv\Scripts\activate
   - Mac/Linux: python3 -m venv venv && source venv/bin/activate
4. Install dependencies: pip install -r requirements.txt
5. Run app: python app.py
6. Open browser: http://localhost:5000
7. Login with: admin / admin123

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Python not found"
Solution: Install Python from https://www.python.org
         Make sure to check "Add Python to PATH"

Problem: "Port 5000 already in use"
Solution: Edit app.py, find "port=5000" and change to "port=5001"

Problem: "ModuleNotFoundError"
Solution: Run: pip install -r requirements.txt

Problem: "Database locked"
Solution: Delete trekking_app.db file and restart

Problem: Can't access http://localhost:5000
Solution: Try http://127.0.0.1:5000 instead

See README.md for more troubleshooting tips!
